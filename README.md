# 星辰御书房

一个以「御书房」为隐喻的个人学习自律 PWA：每日写下御案（任务 + 最低标准），入座专注点亮星辰，修炼心性获得御印，记录错题，晚间奏对复盘，最终在星图档案里看见长期的变化。

视觉方向为「昼夜双境」：白天是宣纸朱批的书房，入座专注时自动转入墨夜星空。

## 功能

| 页面 | 内容 |
| --- | --- |
| 今日 | 今日状态与下一步建议、御案（按天保存）、昨日未完成结转、今日奏对（五问复盘 + 御批） |
| 御书房 | 15/25/45/60 分钟专注，基于时间戳计时（切后台、刷新后可恢复），可绑定御案任务，分心记录与建议 |
| 修炼 | 五维心性修炼（沉稳/自律/洞察/格局/言行），完成后盖御印 |
| 错题阁 | 记录错题与错因，搜索、按错因/待重练筛选，首次重练点亮一颗星 |
| 档案 | 成长阶位与徽记、星图、人格五维雷达图、近 7 日专注、分心档案、奏对录 |
| 设置 | 主题（跟随系统/昼/夜）、入座即入夜、导出/导入备份、清空数据 |

规则说明：

- 只有完整完成一轮专注才点亮星辰；「提前收卷」只记录实际分钟数，不点亮星辰。
- 快捷键：`1`–`5` 切换页面，`空格` 入座/暂停，`N` 新建御案，`/` 搜索错题，`T` 切换昼夜，`Esc` 关闭对话框。

## 数据

所有数据只保存在本机浏览器的 `localStorage`（键 `starryStudyRoom_v1`），没有后端、账号或同步。清除浏览器数据会丢失记录，请定期在「设置 → 导出备份」中保存 JSON。

- 当前数据结构为 `schemaVersion: 2`，任务和复盘按日期保存在 `tasksByDay` / `reviews` 中。
- 首次打开时会自动把 v1 数据迁移到 v2：旧任务列表归入当天，旧复盘按其更新时间归档。导入旧版备份文件同样会迁移。
- 若本地数据无法解析，原始内容会先备份到 `starryStudyRoom_v1_corrupt_<时间戳>` 再以空数据启动，不会直接丢弃。

## 本地运行

无需构建，也没有依赖。

```bash
npm start        # python3 -m http.server 8080，然后打开 http://localhost:8080
npm run check    # 语法检查、Service Worker 预缓存与页面引用一致性、id 引用与重复检查
npm test         # node --test：数据迁移、统计、雷达图等纯逻辑测试
```

需要 Node.js 18+（测试与检查脚本）和 Python 3（静态服务器，也可换成任意静态服务器）。

## 结构

```
index.html          页面骨架、SVG 图标、对话框
css/
  tokens.css        设计令牌（昼/夜两套语义色、字号、间距、动效）
  base.css          重置、外壳布局、导航（手机底栏 / 桌面侧栏）
  components.css    按钮、表单、卡片、提示、对话框等通用组件
  pages.css         各页面专属样式
js/                 按顺序以普通 <script> 加载，共享全局作用域
  store.js          数据模型、迁移、持久化、渲染注册表（不操作 DOM）
  domain.js         纯业务规则与文案（统计、阶位、御批、修炼题库……）
  ui.js             图标、Toast、确认框、主题、路由
  today.js focus.js practice.js radar.js mistakes.js archive.js settings.js
  app.js            启动、快捷键、跨日检测、Service Worker 更新提示
sw.js               离线缓存（缓存优先，新版本提示刷新）
scripts/check.js    静态检查
tests/              node:test 测试
docs/design-system.md  设计系统说明
```

修改 `index.html` 引用的资源时，需要同步更新 `sw.js` 中的 `FILES_TO_CACHE` 列表并提升 `CACHE_NAME` 版本，`npm run check` 会检查前者。
