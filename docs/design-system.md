# 星辰御书房 · 设计系统

方向：**昼夜双境** —— 东方书房 × 现代数字产品 × 克制未来感。

白天是一张宣纸书桌：暖白纸色、墨色文字、朱砂批注。入座专注时书房转入墨夜，表盘与星辰以金色发光。整体靠排版、留白和少量印章元素建立气质，不依赖霓虹、玻璃拟态或大面积渐变。

## 1. 色彩

所有颜色定义在 `css/tokens.css`，组件只引用语义变量。

| 语义 | 昼 · 宣纸朱批 | 夜 · 墨夜 | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#f4efe4` | `#0d1015` | 页面底色 |
| `--surface` / `-raised` / `-sunken` | `#fbf8f1` / `#fffdf8` / `#ece5d6` | `#141820` / `#1a1f28` / `#0a0c10` | 卡片、浮层、凹槽 |
| `--text` | `#1f1b16` | `#ece6da` | 正文 |
| `--text-secondary` / `-tertiary` | `#4a4339` / `#6e6457` | `#bcb4a6` / `#8a8274` | 说明、元信息 |
| `--ink` | `#1f1b16` | `#ece6da` | 主按钮（墨块） |
| `--cinnabar` | `#b5372b` | `#dc5d4f` | 御印、御批、当前导航、焦点环（昼） |
| `--gold` | `#83601b` | `#e0b75a` | 星辰、专注进度、焦点环（夜） |
| `--success` / `--warning` / `--danger` | — | — | 状态反馈 |

**色彩纪律**

- 金色只属于「星辰」，即专注所得；朱砂只属于「御印 / 御批」，即修炼与复盘所得。这样用户一眼能分清两种成就，档案页的星图（金）与雷达图（朱）也因此各有归属。
- 主操作用墨色而不是品牌色，让朱砂保持稀缺。
- 危险操作用 `--danger`，与朱砂明显区分，并始终二次确认。

**对比度（WCAG 2.1）**：正文在两种主题下约 15:1；三级文字约 5:1；朱砂约 5.2:1；昼间金色约 5:1，夜间金色约 10:1。

## 2. 字体与排版

不加载网络字体，使用系统字体栈：

- `--font-serif`：宋体系（Songti SC / Noto Serif CJK SC / 思源宋体 / SimSun），用于页面标题、区块标题、御批、大号数字之外的「文气」内容。
- `--font-sans`：苹方 / Noto Sans CJK / 微软雅黑，用于界面与正文。
- `--font-mono`：等宽，用于计时器和统计数字，避免数字跳动。

字号从 `--text-xs`（12px）到 `--text-3xl`（40px），外加计时器专用 `--text-display`（`clamp` 自适应）。移动端正文 15px，≥768px 为 16px。行高 `tight 1.25 / normal 1.6 / loose 1.85`；`eyebrow` 小标题使用加宽字距。

## 3. 间距、圆角、阴影

- 间距：4px 栅格，`--space-1`（4）到 `--space-16`（64）。
- 圆角：`4 / 6 / 10 / 14`，书页感优先，避免胶囊化；仅标签与开关使用 `--radius-full`。
- 阴影：昼间是纸张的轻微抬起（`--shadow-sm/md/lg`），夜间几乎不用阴影，以边框 `--line` 分层。

## 4. 布局与断点

| 断点 | 布局 |
| --- | --- |
| < 768px | 单列；底部 5 项标签栏；设置对话框为底部抽屉 |
| 768–1023px | 加宽内容区，统计网格变为多列 |
| ≥ 1024px | 左侧 220px 导航栏（显示快捷键提示）；今日页右侧状态栏吸顶；错题阁、档案为双栏 |

内容最大宽度 `--content-max: 720px`，宽版 `--content-wide: 1040px`。

## 5. 动效

- 时长：`fast 120ms`（悬停、按压）、`base 200ms`（展开、切换）、`slow 420ms`（页面进入）、`theme 600ms`（昼夜过渡）。
- 曲线：`--ease-out` 用于进入，`--ease-in-out` 用于往返。
- 标志性动效只有一个：**盖印**（御印 / 御批落下时的缩放 + 墨晕），只在获得成就时出现。
- `prefers-reduced-motion: reduce` 时所有时长归零；首屏渲染前（`html:not(.is-ready)`）禁用过渡，避免闪烁。

## 6. 主题行为

- 设置项：跟随系统（`prefers-color-scheme`）、始终昼、始终夜。
- 「入座即入夜」（默认开启）：专注进行中自动切换为夜；专注中按 `T` 可临时取消，本轮结束后恢复。
- `<head>` 内联脚本在绘制前读取 `starryStudyRoom_theme`，消除主题闪烁；同时更新 `meta[name=theme-color]`。

## 7. 组件

| 组件 | 类名 | 说明 |
| --- | --- | --- |
| 按钮 | `.btn` + `-primary`（墨）/ `-seal`（朱）/ `-secondary` / `-quiet` / `-danger` / `-danger-quiet`，尺寸 `-sm` / `-lg` / `-icon` | 文字按钮高 44px，图标按钮 40px；`disabled` 降低不透明度并禁止指针 |
| 表单 | `.field` `.input` `.textarea` `.select` `.segmented` `.chip` | 错误通过 `aria-invalid` + `#<id>Error` 提示文本呈现 |
| 卡片 | `.panel` `.stat-grid` `.stat-value.is-star` / `.is-seal` | 数字用等宽字体 |
| 列表行 | `.row` `.check[role=checkbox]` | 勾选后焦点保留在原行 |
| 提示 | `.callout` `-seal` / `-gold` | 御批、诊断、建议 |
| 空状态 | `emptyState()` | 图标 + 标题 + 一句引导，可带操作按钮 |
| Toast | `showToast()` | `aria-live` 区域，最多 3 条，可带「撤销」 |
| 对话框 | 原生 `<dialog>`，`confirmAction()` | 焦点陷阱与 `Esc` 由浏览器提供；移动端为底部抽屉 |

## 8. 状态规范

| 状态 | 表现 |
| --- | --- |
| 加载 | 纯本地数据，同步渲染；导入时按钮禁用并显示「正在读取…」 |
| 空 | 每个列表都有专属空状态与下一步引导；图表在无数据时仍绘制坐标轴 |
| 错误 | 表单字段内联错误；存储写入失败、导入失败用错误 Toast |
| 成功 | 成功 Toast；获得星辰 / 御印 / 御批时盖印动效 |
| 禁用 | 今日修炼已完成后「完成」按钮禁用并说明原因 |
| 破坏性操作 | 删除提供撤销；清空、导入覆盖、提前收卷需确认 |

## 9. 无障碍

- 语义地标（`nav` / `main` / `header`），导航 `aria-current="page"`，切页后焦点移到页面标题。
- 所有图标按钮有 `aria-label`；自定义勾选框、开关、单选组使用对应 ARIA 角色并支持方向键。
- 焦点环在昼为朱砂、夜为金色，均为双层（纸色 + 强调色）以保证在任意背景上可见。
- 快捷键在输入框内不触发。
